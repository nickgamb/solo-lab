Pre-demo setup

About 30 minutes the first time; image caches outlive the cluster.

#Run thisWhat it does
1 Once per machine
make machine-setup
 One sudo: *.lab resolves locally and the lab CA is trusted.
2 Build the lab
make up && make verify
 Every layer and demo. Must end with all checks passed.
3 Right screen Open https://kagent.sterling.lab, agent sv-agents / bob-assistant Signed in as bob / bob-demo.
Running it again

make reset

Switching the model
Local, on your GPU (default)
make llm LLM_PROVIDER=ollama
Anthropic (ANTHROPIC_API_KEY in .env)
make llm LLM_PROVIDER=anthropic
OpenAI (OPENAI_API_KEY in .env)
make llm LLM_PROVIDER=openai
