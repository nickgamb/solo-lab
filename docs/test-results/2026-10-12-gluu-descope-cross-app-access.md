# Gluu to Descope: Cross App Access, 2026-10-12

Bob signs in to the Solo UI through Gluu with a passkey; his agent calls Ledgerline Research. Gluu issues the ID-JAG, Descope redeems it for Ledgerline's token, Ledgerline's MCP server accepts it.

| Role | Product |
| --- | --- |
| MCP client (requesting app) | Solo Enterprise for agentgateway (`ai-gateway`), kagent Enterprise (`bob-assistant`), Solo ext-auth (assurance rules) |
| IdP, ID-JAG issuer | Gluu Flex / Janssen (sterling-idp.gluu.info) |
| Authorization server | Descope, Agentic Identity Hub (Cross-App Access) |
| MCP server | Ledgerline Research behind Solo Enterprise for agentgateway (`mcp-gateway`) |

Settings: `ENTERPRISE_IDP=gluu,okta,keycloak,contingency`, `XAA_VOUCHER=gluu,okta`, `RESOURCE_AS=descope` ([IDPS.md](../IDPS.md)).

| Verified | Evidence |
| --- | --- |
| Gluu signs Bob in to the MCP client (OpenID Connect, passkey) | 1 |
| The gateway picks Gluu as the voucher for Bob's session and verifies Gluu's ID token | 2 |
| Gluu issues the ID-JAG for Descope: `aud` Descope's MCP server, `client_id` S&V's Descope client, `aud_tenant`, `resource`, `scope` `research:read`, `email` | 3 |
| The MCP client verifies the ID-JAG before presenting it | 3 |
| Descope validates Gluu's ID-JAG (keys from Gluu's discovery) and issues `research:read` | 4, 5 |
| Ledgerline's gateway and MCP server accept Descope's token | 5, 6 |

Tokens, MCP session IDs, authorization codes and client network details are redacted.
