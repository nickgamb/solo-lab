# Okta to Descope: Cross App Access, 2026-10-12

Bob signs in to the Solo UI through Okta; his agent calls Ledgerline Research. Okta issues the ID-JAG, Descope redeems it for Ledgerline's token, Ledgerline's MCP server accepts it.

| Role | Product |
| --- | --- |
| MCP client (requesting app) | Solo Enterprise for agentgateway (`ai-gateway`), kagent Enterprise (`bob-assistant`), Solo ext-auth (assurance rules) |
| IdP, ID-JAG issuer | Okta, Cross App Access (Integrator org) |
| Authorization server | Descope, Agentic Identity Hub (Cross-App Access) |
| MCP server | Ledgerline Research behind Solo Enterprise for agentgateway (`mcp-gateway`) |

Settings: `ENTERPRISE_IDP=okta,gluu,keycloak,contingency`, `XAA_VOUCHER=okta`, `RESOURCE_AS=descope` ([IDPS.md](../IDPS.md)).

| Verified | Evidence |
| --- | --- |
| Okta signs Bob in to the MCP client (OpenID Connect) | 1 |
| Okta exchanges the ID token for an ID-JAG: `typ` `oauth-id-jag+jwt`, `aud` Descope's resource, `client_id` S&V's Descope client, `resource`, `scope` `research:read`, `act` the AI agent, `aud_tenant` | 2, 3, 4 |
| The MCP client verifies the ID-JAG (`iss`, `aud`, `typ`, `client_id`, `scope`, lifetime) before presenting it | 4 |
| Descope validates the ID-JAG and issues an access token: `scope` `research:read`, `aud` includes `https://mcp.ledgerline.lab/mcp` | 5, 6 |
| Ledgerline's gateway and MCP server accept Descope's token for `account_info` and `sector_outlook` | 6, 7 |

Tokens, MCP session IDs, authorization codes and client network details are redacted.
